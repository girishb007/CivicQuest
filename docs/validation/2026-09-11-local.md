## Environment limitations

Disk space fell from approximately 2 GB to under 1 GB during this session. Container VM initialization previously failed for disk space. The local checks above use native PostGIS, not container/emulator validation.

Desktop files can be cloud-backed/dataless. Reading the existing LICENSE and Git metadata timed out; editable installation could not finish. Tests used dependencies installed directly from pyproject.toml into `/private/tmp/civicquest-runtime`, with `PYTHONPATH=apps/api`. This run does not certify the frozen uv environment. Existing LICENSE and Git files were not replaced.

## Reproduce against an isolated migrated database

```sh
uv sync --frozen --extra dev
uv run alembic upgrade head
CQ_TEST_DATABASE_URL="$CQ_DATABASE_URL" uv run pytest tests/backend -q
uv run ruff check apps/api tests/backend
pnpm install --frozen-lockfile
pnpm typecheck
pnpm --filter @civicquest/web exec next build --webpack
pnpm test:e2e
```

Browser checks expect an already running API and website at `http://localhost:3000`, with that exact CQ_ORIGIN. They currently use installed Chrome; mobile emulation is not physical-phone testing. Database tests use rollback and require a dedicated local/CI database.

## Load baseline

The isolated restored database was expanded to 100,008 clearly synthetic reports. Fifty concurrent simulated clients issued 300 unauthenticated reads (150 feed and 150 map). After bulk-loading report response data and disabling per-request PostgreSQL parallel workers, feed p95 was **661.68 ms** and map p95 **923.94 ms**, with zero HTTP failures. See [machine-readable measurements](load-baseline.json) and `scripts/ops/load_baseline.py`. This is a short local baseline, not sustained production load or authenticated-write throughput. Earlier map p95 exceeded one second before the database concurrency adjustment.

The frozen initial migration also passed on a fresh UTF-8 PostGIS database. Migration 0002 adds the ordered public-report index.

## Final regression pass in this session

All **18 backend tests** and **8 browser tests** passed after fixing a transaction timing race: database dependencies now commit at function scope before HTTP responses are emitted. The FastAPI minimum is pinned to the tested version supporting that behavior. Browser tests cover four scenarios on desktop Chrome and Pixel 7 emulation. The moderator test waits for login completion before navigation. The app is available locally at http://localhost:3000.

Remaining implementation work is listed explicitly in [REMAINING_WORK.md](../REMAINING_WORK.md); these passing checks do not constitute full V1 completion.
